# Fully-set-up-cardputer-adv-guide
How to set up Cardputer adv

#1 go to this website on your computer 
https://bmorcelli.github.io/Launcher/webflasher.html
#2 plugin your Cardputer to your computer 

#3 click latest release, click M5Stack, click cardputer/Cardputer ADV

#4 click install to Cardputer and select your device
 and wait for the install to finish 

#5 get a microsd card (not required but heaviliy reccomened
make sure its 32GB or less, if it is bigger than 32GB
you must make a partition of your SD card that is 32 GB
32K cluster size and Fat32. Insert the SD card into the 
Cardputer

#6 You have now installed the launcher where you can download
apps. I will now show you how to download Bruce firmware
on launcher which can be used for legal hacking. You can 
use the same steps to install other apps

#7 click OTA, it will scan for wifi, select your network
and type in the password.

#8 scroll until you see something along the lines of 
Bruce firmware (or search it in refined search at the top)
press enter on it, press enter again once your on the Bruce page,
select the OTA-SD (or something like that)

#9 go back to the home page by pressing ESC a few times
select SD, find the tab that says downloads, select it
, select the option that says bruce and click install(or something along
those lines) then bruce should open. 

#10 follow these steps for installing any software but note
you likley cant have multiple firmwares installed at the same time.

#11 to learn how to use Bruce either search up a guide or
 figure it out yourself
